Pipeline Architecture

Structured NLP stream parsing replacing regex counters with tokenized entity taxonomies.

[Resume Upload (PDF/DOCX/TXT)] │ ▼ [pdfplumber / Stream Parser] ──► Tokenizes byte streams, extracts text layers │ ▼ [spaCy NER Model Pipeline] ──► Extracts entity spans (LANGUAGES, FRAMEWORKS, CLOUD) │ ▼ [Skill Gap Taxonomy Engine] ──► Categorizes Present vs. Missing competencies │ ▼ [Pydantic v2 Schema] ──► Strict typed response JSON to frontend

Core Design Decisions

  • PDF Byte-Stream Parsing: Direct memory processing avoids saving temporary disk artifacts.
  • spaCy Entity Recognition: Replaced naive keyword counting with contextual token matching.
  • Taxonomy Classification: Matches candidates against grouped domains (Languages, Frameworks, Cloud, Databases).
